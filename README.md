# مهدیه محسنی | لندینگ پیج فارسی

وب‌سایت شخصی استاتیک، فارسی و راست‌چین با HTML، CSS و JavaScript ساده؛ بدون نیاز به نصب یا build.

## مشاهده محلی
فایل `index.html` را در مرورگر باز کنید. برای تست بهتر می‌توانید از افزونه Live Server در VS Code استفاده کنید.

## انتشار در GitHub Pages
1. یک repository جدید در GitHub بسازید.
2. فایل‌های `index.html`، `styles.css`، `script.js` و `README.md` را در ریشه مخزن قرار دهید.
3. در **Settings → Pages**، گزینه **Deploy from a branch** را انتخاب کنید.
4. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.
5. پس از پایان انتشار، آدرس سایت در همان صفحه نمایش داده می‌شود.

## شخصی‌سازی
- متن‌ها، پروژه‌ها و سوابق در `index.html` قرار دارند.
- رنگ‌ها و چیدمان در `styles.css` قابل تغییرند.
- رفتار منوی موبایل و کپی ایمیل در `script.js` است.
- فونت Vazirmatn از Google Fonts بارگذاری می‌شود و در صورت نبود اینترنت، فونت‌های سیستمی جایگزین می‌شوند.

## یادداشت درباره محتوا
اطلاعات حرفه‌ای و اعداد نمونه‌های کاری بر اساس رزومه انگلیسی موجود وارد شده‌اند. پیش از انتشار عمومی، تاریخ‌ها، اعداد و جزئیات محرمانه را یک‌بار بازبینی کنید. ایمیل، تلفن و لینکدین همان اطلاعاتی هستند که در نسخه قبلی رزومه/سایت استفاده شده‌اند.
